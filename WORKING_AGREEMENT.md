# Team Working Agreement & Definition of Done

## Working Agreement
- Core Communication: Discord / Messenger.
- Task Workflow: All work follows Branch -> PR -> Merge cycle.
- PR Tracking: All merged PR links must be logged in Column I of the project spreadsheet.

## Definition of Done (DoD)
- Code/Files pushed to dedicated feature/task branch.
- Pull Request opened and reviewed.
- Merged into `main` branch.
- PR link documented in master task tracker.
